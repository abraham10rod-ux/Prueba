CAPA 2 – ENLACE DE DATOS

Switch Industrial (Conmutador de Red)

Un Switch opera principalmente en la Capa 2 (Enlace de Datos) del modelo OSI. A diferencia de un concentrador antiguo (Hub) que enviaba datos a todos los puertos, el Switch aprende las direcciones físicas MAC de cada dispositivo conectado y construye una tabla CAM para enviar las tramas únicamente al puerto de destino exacto, evitando colisiones y maximizando el ancho de banda. Además, permite crear redes virtuales segmentadas llamadas VLANs (IEEE 802.1Q).

Ficha de Identificación
Identificador usado: Dirección MAC (48 bits)
Unidad de Datos (PDU): Trama (Frame Ethernet)
Rol en Proyecto SENA: Une Cámara, Servidor y Router

Fundamentos de Deep Learning y Visión Artificial

¿Qué es YOLO? ("You Only Look Once")

YOLO revolucionó la detección de objetos al analizar toda la imagen en una sola pasada de red neuronal convolucional (CNN) en tiempo real.

SINGLE-STAGE DETECTOR (TIEMPO REAL)

Cómo funciona YOLO en una sola mirada

YOLO divide la imagen de entrada en una cuadrícula de S × S celdas. Cada celda predice simultáneamente múltiples cuadros delimitadores (Bounding Boxes), un puntaje de confianza y las probabilidades de clase en una única evaluación de red neuronal.

Velocidad de Inferencia: 30 – 120+ FPS (Tiempo Real)
Pasadas por Imagen: 1 única pasada (End-to-End)

Fórmula del Tensor de Salida

Cada caja predicha contiene 5 valores base + las probabilidades de clase:

[ x_centro, y_centro, ancho (w), alto (h), Confianza, Clases... ]

Transfer Learning y Pesos Neuronales

¿Qué es un Modelo Pre-entrenado? (YOLOv8n + Dataset COCO)

Comprende cómo se almacenan los conocimientos de una red neuronal en archivos de pesos y qué clases reconoce de fábrica.

1. Concepto de Modelo Pre-entrenado

Entrenar una red neuronal desde cero requiere millones de imágenes y semanas de cómputo en GPUs costosas. Un modelo pre-entrenado ya pasó por ese proceso: sus millones de neuronas ya aprendieron a identificar formas, contornos, sombras y objetos comunes.

2. Archivo de Pesos (yolov8n.pt)

La extensión .pt (PyTorch) guarda los parámetros numéricos (pesos sinápticos y sesgos) ajustados durante el entrenamiento. La letra "n" (Nano) indica que es la versión más ligera (~6.2 MB y 3.2M parámetros), diseñada para correr con baja latencia en servidores o dispositivos IoT/Edge.

3. Dataset COCO (80 Clases Nativas)

El modelo base fue entrenado con MS COCO (330,000 imágenes en 80 categorías cotidianas como persona, auto, bicicleta, motocicleta).

Punto Clave para Sustentación SENA: Clases Nativas vs. Transfer Learning

El modelo estándar yolov8n.pt detecta de forma nativa las 80 clases de COCO (por ejemplo, persona y auto en nuestra escena industrial), pero NO detecta cascos ni chalecos de seguridad de manera nativa. Para detectar Elementos de Protección Personal (EPP), se aplica Transfer Learning (Fine-Tuning): se congelan las capas iniciales del modelo pre-entrenado y se re-entrena únicamente la capa final con un dataset etiquetado de cascos y chalecos.
